00 / MENTAL MODEL

先建立正确的“AI 建模”模型

AI 的强项是读文、归纳、规划与写代码；CAD 的内核只认明确几何与约束。把两者接起来，关键是“让 AI 提出方案，让 CAD 执行，让校验决定是否通过”。

!

最重要的一句话：工程图转三维不是“文件转换”。图只定义了若干视图、尺寸、公差与设计意图，模型还必须补齐隐藏结构、特征顺序与参数关系，所以最终模型必须可编辑、可追溯、可验证。

理解尺寸归属

AI 先做“审图员”

把每一个尺寸变成结构化记录：数值、上下偏差、单位、属于哪个视图、约束哪个几何、是否存在冲突或缺失。

不要直接生成先要清单
规划特征树

再做“工艺规划员”

先决定基准面、草图轮廓、主体、孔、槽、阵列、倒角与圆角顺序，并给关键尺寸起稳定名称。

重建特征命名参数
执行CAD API

最后才“动手建模”

让 AI CAD 工具或 SolidWorks API 执行明确步骤。模型通过包络、体积、孔位、孔径和重建测试后，才算完成。

人工签核不可跳步
2026 工具格局

图纸 → CAD

Backflip 的 Drawing to CAD、Adam 的 2D Drawing to 3D 都已把“带尺寸图纸”作为入口，但仍需人工处理歧义。

CAD 智能体

Adam 宣称可通过 Windows connector 在运行中的 SolidWorks 里检查与修改模型；这是“操作现有 CAD”，不是替代许可证。

代码化 CAD

Zoo 的 Zookeeper 与 SolidWorks API 路线，都把自然语言或参数转成可编辑几何和特征。程序化路线可控，但需要测试。

网格生成分支

图片或草图生成 Blender / Meshy 模型，适合外观与概念，不适合作为精密工程图尺寸的唯一来源。

!

关于“免费版 / 盗版 SolidWorks 2025”：它不是官方免费永久版。功能缺失、联网连接器拒接、宏或 API 失效、插件与安全风险都必须计入。商业 AI 连接器通常按“正常运行的授权 SolidWorks”设计；在没有合法授权的环境中，优先用本机宏录制、Python API 试验和隔离环境，不要把关键成果依赖在来源不明的插件上。

03 / PROMPTS

把 AI 用成审图员，而不是许愿机

每次都先索取过程性输出：尺寸台账、疑问、特征计划、校验点。提示词里明确“信息不足就停”，比要求它“一定要画出来”更可靠。

1. 图纸审阅 / 尺寸台账

你是机械制图审图员。请只审阅我提供的二维工程图，暂不要建模，也不要猜测缺失尺寸。

输出以下四部分：
1. 图纸基本信息：图号、修订版、单位、投影法、比例、材料、视图列表。
2. 尺寸台账：用 Markdown 表格逐项列出“尺寸编号 | 数值 | 上下偏差/公差 | 单位 | 所在视图 | 约束对象 | 明确/歧义/缺失”。
3. 冲突列表：同一特征出现多个值、尺寸链闭合异常、视图矛盾，全部指出并引用位置。
4. 建模前必须确认的问题：按重要性排序。

原则：
- PDF 中的可选中文字是主证据，图像只用于核对图形关系。
- 不得根据像素比例推测未标注尺寸。
- 不清楚的孔深度、通孔/盲孔、沉孔、倒角、圆角、阵列规则必须列为问题。
- 最后给出一个“能否进入特征规划”的判断：可以 / 不可以，并说明原因。

2. 特征计划

现在仅根据已确认的尺寸台账做建模规划，不要执行建模。

请输出：
1. 零件类型和建模策略（板类、回转体、钣金、铸件等）。
2. 推荐的基准面和坐标原点及理由。
3. 从基础草图到最终特征的顺序，每步包含：特征名、草图、方向、合并/切除、关键参数、依赖关系。
4. 参数命名表：参数名、含义、标称值、单位、来源尺寸编号。
5. 应使用阵列/镜像/方程式复用的关系，避免重复硬编码。
6. 为保证可编辑性，哪些尺寸必须留在草图中，哪些可作为特征参数。
7. 如果任何必要信息缺失，明确停止并列出问题，不得自行补值。

目标是在 SolidWorks 中得到可重建、可改名、可改参数的专家式特征树，而不是只追求外观相似。

3. SolidWorks API / 宏脚本

你是保守的 SOLIDWORKS 2025 API 工程师。请根据已批准的特征计划和变量表编写可审查脚本。

要求：
- 不在未保存的文档或原始客户文件上执行。
- 每一步都有命名实体和参数检查，失败立即停止并输出错误。
- 不硬编码未批准尺寸；从集中参数表读取。
- 标注使用的对象和方法，并链接或引用 2025 API 文档名称。
- 先输出伪代码与风险点，等我确认后再输出完整代码。
- 代码完成后，给出逐步重放、撤销与恢复方案。
- 最后列出自动校验项：包络尺寸、孔数量、孔直径、孔位、体积、特征重建。

当前目标：在 SolidWorks 中由已核验的尺寸台账构建可编辑参数化零件。

4. 模型反向审图

你是独立的质检员。请不要为模型辩护，只按证据核验。

输入：原始 PDF 的尺寸台账、模型截图/工程图、关键参数导出、体积和包络尺寸。
输出一张检查表，逐项列出：
- 关键尺寸：图纸值、允许偏差、模型值、误差、是否通过。
- 特征：孔/槽/台阶/螺纹/倒角/圆角的数量和位置。
- 设计意图：修改一个关键参数后，依赖特征是否按预期更新。
- 重建状态：有无错误、警告、悬空草图、未定义草图。
- 结论：PASS / REVIEW / FAIL，并写明阻断项。

不要用“看起来一致”代替数值比较；如果缺少证据，就标为 UNVERIFIED。

05 / QUALITY GATE

模型像不像不重要，能不能验证才重要

AI 可以提出特征树，但放行权属于尺寸证据。将“正确尺寸来源”和“生成模型结果”分开保存，任何差异都要能被看见。

最容易被忽略的 8 个漏洞

  • 把 PDF 截图当尺寸来源，丢失小数点或单位。
  • 只检查外观轮廓，不检查孔深、通孔/盲孔与沉孔。
  • AI 猜出图纸未标的第三维，却没有把假设写回记录。
  • 特征树能生成但重建失败，局部存在悬空或未定义草图。
  • 尺寸都“对”，但孔位没有按基准或设计意图约束。
  • 只做一个零件就决定采购，没有按类别评估错误率。
  • 忽略图纸修订版、投影法、比例与公差体系。
  • 把生成网格当成参数化 CAD，无法稳定改型。

放行前检查

建议台账字段
检查对象图纸证据模型证据通过规则失败动作
包络尺寸长、宽、高及单位实体 bounding box按图纸公差比较停止并回溯草图/主体
孔系统数量、直径、深度、基准与位置拓扑 + 轴线/中心坐标数量完全一致，位置按基准进入人工复核
特征可编辑性设计意图和关键参数特征树 + 参数依赖改关键参数依赖特征正常更新不视为可用模型
重建质量无直接对应项重建状态与诊断无未定义或悬空约束修复或退回重规划
体积/质量已知材料与公差CAD 质量属性与基准模型比较标记异常并检查几何
优化指标： 净节省时间 = 人工建模基线 − (AI 执行时间 + 人工审图 + 修正 + 校验)

不要只统计“一键生成用了多久”。真正需要优化的，是关键尺寸通过率、重建成功率、人工修复分钟数与不同零件族的可复用度。

07 / GLOSSARY

以后看教程时，先把词对上

这些词会把工程图、AI 和 CAD 自动化三个圈子连起来。

参数化建模

模型由尺寸、约束和特征关系决定，而不是只保存一串固定几何。改关键参数后，下游特征能按设计意图更新。

特征树 / Feature Tree

SolidWorks 中按顺序记录主体、切除、孔、阵列、圆角等操作的构造历史。可编辑特征树比 STEP 网格更接近可维护模型。

尺寸台账

把图纸上的尺寸结构化：数值、单位、公差、来源视图、约束对象和确认状态。它是 AI 与 CAD 之间最重要的中间产物。

VLM / 多模态模型

能同时读取图像和文字的模型。适合解释视图关系和生成待确认问题，但视觉相似不等于尺寸正确。

API / COM

程序调用 SolidWorks 功能的接口。宏录制给你现实可用的调用样例，Python 可以通过 Windows COM 接口驱动本机软件。

Drawing to CAD

从二维工程图重建三维模型的产品类别。重点不是“打开 PDF”，而是提取尺寸、补齐关系、生成特征并校验。

Scan / Mesh to CAD

从扫描网格或点云识别几何并重建成可编辑特征。属于逆向工程分支，输入与 2D 图纸完全不同。

确定性校验

用数值而不是感觉判断结果，例如包络尺寸、孔中心坐标、孔径、体积、质量和重建状态。它是自动化最关键的刹车。

净节省时间

人工基线减去 AI 执行、审图、修正和校验所花时间。只有长期为正，自动建模才真正提升效率。

从现在开始，别追求“全自动”。

先完成一张图的“尺寸台账 → 特征计划 → 手工模型 → 数值对齐”。一旦这条闭环稳定，再让 AI 接手其中一段。
