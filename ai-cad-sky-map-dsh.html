01

先把话说明白：能做到什么，做不到什么

你想要的“一句话生成 SolidWorks 模型、设计树还能编辑”，在 2026 年 10 月这个时间点，没有现成产品能直接给你。但有一条路能自己搭出来，而且不需要你会写代码——只需要你会复制、粘贴、点运行。

能做到

  • 一句话描述 → 宏 → 带完整特征树的零件
  • 改几个数字重跑，30 秒出新规格
  • 法兰、阶梯轴、齿轮坯这类“有固定套路”的件
  • 全程离线，不联网、不买插件

做不到

  • 任意零件一句话完美生成
  • 曲面、复杂装配、外观件（放样/抽壳）
  • 让 AI 直接吐一个 .sldprt 文件给你
  • 一次成功、永不返工

要花多久

  • 2 天：跑通 3 类件，知道哪里会坏
  • 2–4 周：新零件也能自己调出来
  • 持续：把宏攒成你自己的标准件库
  • 前提：每天真的动手，不是只看

代价

  • 你要看得懂 5 行代码在干什么
  • 你要会看报错、会改一个数字
  • AI 写的宏一次成功率约 6–8 成
  • 复杂件的失败率会明显更高
三个必须接受的现实 第一，AI 目前不会“画”SolidWorks，它只会“写命令”——所以你要的是让 AI 写对命令，而不是让它理解你的零件。
第二，任何把 STEP/STL 导进 SolidWorks 的方案，都会毁掉特征树（只会留下一个 Imported1）。这是路线选择的分水岭。
第三，“通用宏”是个陷阱。越通用越脆，先做“一种零件一个专用宏”，再谈复用。

四条常见误解，先拆掉

你可能以为实际情况
AI 能直接给我 .sldprt不能。SolidWorks 文件格式封闭且带历史依赖，云端服务没有理由、也没有接口去写它。所有“文生 CAD”都给你 STEP / STL / 网格。
STEP 导进来再改改就是参数化不是。STEP 只记录几何面（B-rep），不记录“先拉伸再切除”的历史。导入后是“死实体”，改一个孔要重新做布尔。
宏写得越通用越好反了。通用宏要处理无数边界情况，AI 写十个通用宏不如写一个专用宏稳。先“一个零件一个宏”，稳定后再抽参数。
装个 AI 插件就能自动建模市面插件多数做渲染、选型、网格减面、图纸识别，不生成特征树。真做特征树这条路，目前只有“宏/API”这一条。
02

认知地图：AI 建模其实有四条路

“AI 建模”是一个被说烂的词。它至少包含四种完全不同的技术，产出物、能改不能改、要不要联网，全都不一样。你只需要认清一件事：你要的是“建模历史”，不是“几何形状”。

路线 A云端文生 CAD
一句话→ 云端生成→ STEP 下载→ 导入 SW = Imported1
特征树死了
路线 B脚本化 CAD
Python 代码→ CadQuery 内核→ STEP→ 导入 SW
同样没有历史
路线 C本地宏 / API 代理
一句话→ AI 写 VBA→ SW 执行命令→ 原生特征树
你要走这条
路线 D工程世界模型
照片/文字→ 拆 BOM→ 逐零件建模→ 装配
SKY-001 等
为什么只有路线 C 给你特征树？ 特征树的本质不是“模型长什么样”，而是“用了哪些命令、按什么顺序、带什么参数”。STEP 只存结果（面、边、B-rep），不存过程，所以导入后无从还原。而路线 C 是让 SolidWorks 自己执行命令——命令执行完，历史自然就留下了。

所以“AI 建模”这件事，拆成三层能力

① 表达

把脑子里的零件，说成 AI 能执行的规格：外形、尺寸、孔位、约束、材料。说不清，AI 一定写错。

② 生成

AI 把规格翻译成 API 调用序列。它不需要“会建模”，只需要“会查文档 + 会写循环”。

③ 验收

你判断结果对不对：尺寸、壁厚、孔边距、能不能加工。这一层 AI 替不了你，也是你最值钱的地方。

一句话记住整张地图 网格模型解决“看起来像”，参数化 CAD 解决“能改、能造”。你缺的从来不是生成能力，是“生成历史”的能力。路线 C 之所以成立，是因为它把 AI 从“画家”换成了“操作员”。
03

周末冲刺线：两天，四个时段

按“目标 → 动作 → 完成标志”排。每个时段 2 小时左右，做不完就顺延，别跳步——跳过的每一步，都会在后面变成一次卡死。

DAY 1先让它动起来
上午 · 2h

录一个宏，看见“鼠标动作 = 代码”

不写代码。打开 SolidWorks，点“录制宏”，随便画一个圆、拉伸 20mm、停录、保存。

然后打开宏编辑器，从上往下读一遍。你会看到 CreateCircleByRadius 和 FeatureExtrusion3——那就是你刚才点的两下鼠标。

完成标志：你能指着代码说出“这行是我画的圆”
下午 · 2h

跑通宏 A（法兰盘），然后故意改坏它

复制第 06 节的宏 A，新建零件 → 工具 → 宏 → 新建 → 粘贴 → F5。

跑通后，把 HOLE_N 从 6 改成 10，再跑；把 PCD 改到比外径还大，看它怎么报错。

完成标志：同一个宏，三种孔数都出来了；你知道报错长什么样
DAY 2从“跑通”到“会调”
上午 · 2h

宏 B + 宏 C：换一种几何，换一种思路

阶梯轴教你“用起始面偏移叠圆柱”，齿轮坯教你“一张草图里画 20 个齿槽再一次切完”。

重点不是代码，是这两种“避开选面”的建模策略——它们决定了宏稳不稳。

完成标志：三类零件的特征树都干净、都能改参数
下午 · 2h

用提示词生成器，描述一个你自己的零件

打开第 05 节的生成器，写一句话，拿到结构化提示词，丢给 AI，得到宏，跑。

大概率第一次会失败——这一段的收获就是“失败长什么样、怎么改”。

完成标志：一个不在教程里的零件，你自己调出来了
时间不够怎么办 只做 Day 1 下午那 2 小时，你也能拿到“一句话出法兰”的完整体验。Day 2 是让你从“会用”走到“会调”，可以拆成两个周末。
04

部署：15 分钟把环境弄对

这一步最容易翻车，也最容易一次做对。四个动作，按顺序来。

让 SolidWorks 允许运行宏

工具 → 选项 → 系统选项 → 安全性，把“宏安全性”调低到允许运行（或在弹出提示时选“启用宏”）。

如果找不到，直接在 工具 → 宏 → 运行 里选一个 .swp，弹窗出现时选“启用”。公司电脑可能被组策略锁死，那就只能手动建模。

建一个固定的宏文件夹

C:\SW_MACROS\，以后所有 .swp 都放这里，并且把它加进“受信任位置”。

好处：不会每次都被安全提示打断；换电脑时整个文件夹拷走就能用。

打开“录制后自动编辑”

工具 → 选项 → 系统选项 → 常规，勾选“录制宏后自动编辑宏”。

这样你每次停录，编辑器会自己弹出来，省掉“文件在哪”的困惑。

把宏挂到工具栏（可选，但很值）

工具 → 自定义 → 宏，把常用宏拖到工具栏，起个中文名，比如“法兰”。

以后就是“点一下按钮，出一个零件”，比开菜单快得多。

第一课：录制宏，看清 AI 到底在替你写什么

这是整份地图里最重要的一步。做完它，你对“AI 建模”的恐惧会消失一大半。

STEP 1开始录制工具 → 宏 → 录制，随便起名
STEP 2画一个圆前视基准面 → 圆 → 标注 Ø80
STEP 3拉伸 20拉伸凸台，深度 20mm，确定
STEP 4停止并编辑工具 → 宏 → 停止，编辑器自动打开
STEP 5读那两行找到 CreateCircleByRadius 和 FeatureExtrusion3

你录出来的代码，大概长这样（省略了无关行）：

录制宏的真实产物（片段）
看懂这三行，你就看懂了全部 CreateCircleByRadius 0,0,0, 0.04 —— 在原点画半径 0.04 米的圆（就是 Ø80mm，注意是米）。
FeatureExtrusion3 True, False, ... 0.02 ... —— 拉伸 0.02 米 = 20mm，后面一串 True/False 是方向、拔模、合并这些开关。
所以“AI 建模”= 让 AI 按顺序把这些函数排好。它不需要长眼睛，只需要知道参数。
三个必踩的坑，提前说 ① 单位是米。所有长度写 0.02，不是 20。写 20 会得到一个 20 米长的零件（然后你会以为软件坏了）。
② 基准面名字会本地化。英文界面叫 Front Plane，中文界面叫 前视基准面，写死一个就有一半人跑不了。
③ 别用坐标去“点”面。SelectByID2 选面在改尺寸后极易失效，这是宏“跑一次就坏”的头号原因。

05

核心回路：一句话怎么变成一棵树

这条回路你只要跑顺一次，后面所有零件都是它的变体。五个节点，缺一不可；大多数人卡在 ② 和 ⑤。

① 描述说清规格外形 + 关键尺寸 + 孔位 + 材料，别用形容词
② 提示词加硬约束单位、API、禁止选面、失败处理
③ 生成AI 出 VBAGPT / Claude 更稳，一次只要一个零件
④ 运行粘贴执行新建零件 → 宏 → 粘贴 → F5
⑤ 验收量三个数外形、孔位、壁厚；不对就回到 ①

② 是胜负手：四段式提示词

第一段 · 角色与目标

“你是 SolidWorks 2025 VBA 工程师，写一个 Sub main，在已打开的空白零件里生成……”
别让它建文档、别让它猜路径，减少失败点。

第二段 · 精确规格

全部用“数值 + 单位 + 位置关系”。“大概”“差不多”“美观”一律删掉，AI 对形容词的翻译一定是错的。

第三段 · 硬约束

只用 FeatureExtrusion3 / FeatureCut4；换算成米；不选面，用基准面 + 双向完全贯穿；每个特征判空。

第四段 · 失败与验收

“创建失败就 MsgBox 说明原因，不要静默退出；最后 ZoomToFit 并重建。”
没有这段，你会得到“跑完什么都没发生”。

用哪个 AI 写宏：四个工具的实测倾向

这不是跑分，是按“写 VBA + 少编 API”的稳定性给的排序。你手上有四个，别一个用到底，按任务分工。

工具强在哪用来做什么注意
ChatGPT（GPT-5 系）VBA / C# 语法最稳，参数顺序不容易错第一次生成、复杂特征链中文零件描述偶尔理解偏，尺寸要复核
Claude / Gemini长代码、读官方文档强改错、重构、让它读 API 页面容易“过度设计”，加一堆你不需要的特征
DeepSeek中文理解好、便宜、快写中文注释、解释代码、日常小改复杂 API 调用容易漏参数
豆包 / 通义 / Kimi免登录、响应快应急、翻译英文文档成功率最低，别用来写复杂件
怎么验证这张表对你自己成立 拿同一个提示词，四个工具各跑一次宏 A，看谁第一次就零报错。三个零件之后，你会得到属于你的排序——比任何评测都准。

宏报错时，先定位到“哪一类”，再把错误原文贴给 AI。光说“跑不了”，AI 只能瞎猜。


    

      

        
现象真正原因怎么修

        
          
编译错误：用户定义类型未定义宏没有引用 SldWorks 类型库把 As SldWorks.SldWorks 等类型名删掉，统一改成 As Object；或工具 → 引用里勾选 SolidWorks 类型库

          
运行时错误 91：对象变量未设置没有打开的零件，ActiveDoc 是空的先新建一个零件再运行；代码里已经有判空，若仍报错说明宏没跑到判断那行

          
运行时错误 438：对象不支持该属性API 名字拼错，或该版本没有这个方法用录制宏录一遍同样的操作，抄它生成的函数名——这是最可靠的对齐方式

          
“参数个数不对”不同版本 API 参数数量变了同样：录一遍，数一下它给了几个参数，照着补/删

          
跑完什么都没发生草图没闭合 / 没选中基准面 / 特征是 Nothing加 If feat Is Nothing Then MsgBox "失败"；检查草图是否首尾相接

          
零件巨大或巨小 1000 倍单位没换算，API 只认米所有长度 /1000；角度用弧度 *3.14159/180

          
切除切反了，切到空气切除默认方向与草图法向相反改用双头 + 两端完全贯穿（宏里 False, ..., 1, 1 就是这个意思）

          
找不到 Front Plane中文界面基准面叫“前视基准面”两种名字都试；或让用户手动先选中一个面，宏里不再指定

          
改尺寸后特征报红孔超出实体、壁厚变负、圆角半径大于棱边加参数校验：PCD + HOLE_D < OD、BORE < OD、KEY_T < (OD-BORE)/2

          
多出一堆实体不合并Merge 设了 False，或两段没接触把 Merge 设为 True；确保相邻段在同一个面上相接（必要时重叠 0.05mm）

        
      

    


    

      给 AI 报错的正确姿势
      “这段宏在第 14 行报 运行时错误 438，我用的是 SolidWorks 2025 中文版，代码如下：……。请只改出错的那一处，其余不要重写。”

      “只改一处、不要重写”这句话能省你一半的返工——否则 AI 会把整个宏重排一遍，引入新错。
    

  







  

    
08
优化四张表：从“能跑”到“敢用”

    
你说的优化有四个方向，它们的方法完全不同，别混着做。先做稳健，再做效率，最后才是可制造性。


    

      

        
① 稳健性 · 改了尺寸不崩

        
    
          
  • 不选面：全部用基准面 + 贯穿，别用 SelectByID2 点面
    • 
          
  • 参数集中：所有尺寸只在顶部 Const 区出现一次
    • 
          
  • 边界校验：孔不能破边、壁厚不能为负、圆角不能大于棱边
    • 
          
  • 顺序固定：先大形体，再孔，最后圆角——圆角放最后，改尺寸最不容易挂
    • 
          
  • 每次重建：结尾加 EditRebuild3，让错误当场暴露
    • 
        

      

      

        
② 效率 · 少返工、出得快

        
    
          
  • 建模板：零件模板里预置材料、单位、视图，宏只画几何
    • 
          
  • 挂按钮：常用宏拖到工具栏，一键出件
    • 
          
  • 批量配置：一个宏 + 一张 Excel 参数表，循环生成一串规格
    • 
          
  • 录制宏当字典：不会写的操作先录一遍，抄现成代码
    • 
          
  • 先跑通再优化：别一开始就追求“通用”，那是最大的时间黑洞
    • 
        

      

      

        
③ 可制造性 · 能直接拿去加工

        
    
          
  • 最小壁厚：钢件 ≥1.5mm，铝件 ≥1.2mm，注塑件按材料查
    • 
          
  • 孔边距：孔壁到边缘 ≥1.5×孔径，否则容易崩边
    • 
          
  • 内圆角 ≥ 刀具半径：铣削内角不能是尖角，R 至少等于刀半径
    • 
          
  • 公差与基准：宏只管几何，公差还得你在工程图里标
    • 
          
  • 拔模：注塑/铸造件别忘了 1–3° 拔模，宏里可加 Dchk1=True
    • 
        

      

      

        
④ 提示词 · 让 AI 少胡说

        
    
          
  • 给数字不给形容词：删掉“合理”“美观”“适当”
    • 
          
  • 给硬约束：单位、只能用哪些 API、禁止选面
    • 
          
  • 一次一个零件：别让 AI 一次写“整套装配”
    • 
          
  • 要求完整代码：明确说“不要省略号、不要伪代码”
    • 
          
  • 先要清单再要代码：让它先输出“特征顺序 1→5”，你确认后再写
    • 
        

      

    


    

      顺序建议
      先花半天把①做扎实（不选面 + 参数集中 + 判空），你会发现后面 80% 的报错自动消失了。直接冲②③，只会在一个不稳的地基上反复返工。
    

  







  

    
09
SKY-001：那个“很牛逼但还不能用”的东西

    
你听到的传闻基本是真的，但被剪掉了最关键的一半：它是“工程世界模型”，不是“SolidWorks 插件”，而且现在只有 waitlist。


    

      2026-10 发布 · 未公开
      
SKY-001 · Skyfall AI

      
加拿大初创 Skyfall AI 发布的“首个工程世界模型”。它的思路不是“一次吐出形状”，而是像工程师一样分步做：先给几个粗略方案 → 拆成 BOM 和零件 → 每个零件从草图开始拉伸/切除 → 分层装配。这恰好是你想要的那种“有过程”的建模。


      

        
79.7%3D CAD IoU（官网自报）

        
3.9s单样本生成耗时

        
1/150成本，对比 LLM 方案

        
Waitlist当前获取方式

      


      

        
① 发散一张图/一句话 → 多个粗略方案

        
② 拆解分层 BOM，拆到螺钉垫圈

        
③ 建模逐零件画草图、拉伸、切除

        
④ 装配按层级组装成完整产品

      


      
skyfall.ai/sky-001（官网 + waitlist） · 发布视频 · 中文解读

    


    
为什么现在不能把它当路线

    

      

        
没有入口

        
官网只有 waitlist，没有公开 API、没有定价、没有自助试用。你搜到“还不能使用”，是准确的。

      

      

        
格式未验证

        
官方描述是生成 3D asset / assembly，在标准 3D 查看器里看。没有任何证据表明它能导出带特征历史的 SolidWorks 文件。

      

      

        
指标是自报

        
79.7% IoU、3.9 秒、1/150 成本，都来自官网对比表，没有第三方复现。“世界模型”目前是营销词，不是可验证的技术标准。

      

    


    

      它来了，你怎么判断是“真能用”还是“又一个 demo”？
      看四件事：能不能导出 STEP / Parasolid（能导出才有资格谈进 CAD）；有没有特征历史（不是网格、不是死实体）；改一个参数能不能重算（不能重算就还是“生成器”）；价格是不是按件算（按件算才可能日常用）。
    


    
现在该练什么，等它来了你能接住

    
好消息是：为路线 C 练的能力，到路线 D 一点不浪费。世界模型再强，最后也要落到“参数、约束、可制造性”上，而这些只有你能判断。


    

      

        
现在练（同时也是周末任务）

        
    
          
  • 把零件说成规格的能力：外形、尺寸、孔位、材料
    • 
          
  • 看懂特征顺序：为什么先大形体后孔、圆角为什么放最后
    • 
          
  • 验收能力：一眼看出壁厚不够、孔会破边
    • 
          
  • 参数化底子：方程式、设计表、配置（你已经有）
    • 
        

      

      

        
它来了再学（现在学是浪费）

        
    
          
  • 它的提示词语法、账号体系、计费方式
    • 
          
  • 它的导出格式与 SW 的兼容细节
    • 
          
  • 它的 API / 批量调用方式
    • 
          
  • 它的“重算”机制到底怎么工作
    • 
        

      

    


    

      判断时间线的方法
      盯三个信号，不用天天刷新闻：① 官网 waitlist 变成“Sign in / Pricing”；② 出现“Export: STEP / Parasolid / SLDPRT”字样；③ 有人拿它和 Toolbox 标准件做对比测试。三个里出现两个，才值得你花时间迁移。
